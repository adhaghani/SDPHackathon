# NotificationBell

Compact header icon button with a small circular unread count.

**Consumer provides:** the unread count and the link to `/notifications`.

- No count when there are none. Counts above 99 display as `99+`.
- The count is a `coral` circle with `ink` numerals and a `surface` ring that separates it from the button.
- The accessible name includes the count ("Notifications, 3 unread").
