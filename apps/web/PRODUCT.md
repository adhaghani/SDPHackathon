# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

BorrowLah serves township residents, township managers, guards, and community event organisers. This branch adds a judges preview for people evaluating the project without an account.

## Product Purpose

Connect neighbour sharing, community participation, visitor access, and township planning. The judges preview demonstrates selected workflows with fictional seeded data.

## Capabilities and Constraints

The user requested four one-click perspectives, a project overview, before-demo notes, interactive sample actions, and explicit notices for unsupported actions. Preview actions must remain in the browser, with no database connection. Only the live app at borrowlah.my uses database-backed workflows. The user confirmed a branch domain on the existing Vercel project for judges.borrowlah.my and preservation of the existing lime, ink, and paper design.

## Evidence on Hand

Existing app routes, booking state transitions, guard console, event attendance tools, branding, tokens, and local illustration assets are the implementation references. Preview figures are fictional examples, not pilot or measured results.
